# pssetools - Documentación Oficial

Bienvenido a la documentación de **pssetools**, una colección de módulos y utilidades en Python diseñadas para automatizar y extender las capacidades de **Siemens PSS®E**.

## 📌 Visión General
`pssetools` permite a los ingenieros de sistemas de potencia simplificar tareas repetitivas mediante una interfaz gráfica intuitiva, evitando la necesidad de escribir scripts de Python complejos para cada ejecución.

### Componentes Principales
- **GUI Principal**: Centro de control para descubrir y ejecutar programas de automatización.
- **Programas Ejecutables**: Scripts predefinidos para flujos de carga, análisis dinámicos y más.
- **Herramientas de Análisis**: Módulos avanzados como el Análisis de Sensibilidad.
- **Utilidades de Exportación**: Conversión de resultados de PSS®E a formatos Excel/Pandas.

## 🚀 Inicio Rápido

Para iniciar la herramienta desde la consola interactiva de PSS®E:

```python
import pssetools
pssetools.gui()
```
